# Rockwall NSI Flood Building Versions

Contains:

- 50 original NSI buildings
- 10 synthetic geometry revisions
- 10 synthetic height revisions
- LOD0 footprint polygons
- LOD1 MultiPatch buildings
- Effective 1% annual-chance NFHL polygons

`fd_id` links each synthetic revision to its original building.

`BLDHEIGHT` is the extrusion height in meters.

Geometry types:

- NSI buildings: Point
- LOD0: Polygon
- LOD1: MultiPatch
